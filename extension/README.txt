딸깍컷 / SlopCut / Edge 확장 프로그램 1.5.0

1.5.0 변경
- 한국어 이름을 딸깍컷, 영문 이름을 SlopCut으로 변경했습니다.
- 브라우저 표시 언어에 따라 확장 이름과 제목을 적용합니다.
- 기존 설치 폴더와 저장 키를 유지하여 차단 목록과 테마 설정을 보존합니다.
- 관리 화면의 기능 문구는 현재 한국어입니다.
- GitHub 저장소 이름: slopcut-extension.


1.4.1 변경
- Windows/Edge의 동작 줄이기 설정 때문에 차단 애니메이션이 생략되던 문제를 수정했습니다.
- 차단 버튼을 직접 누르거나 미리보기를 재생하면 동작 줄이기 설정과 관계없이 효과를 표시합니다.
- Windows나 브라우저의 설정은 변경하지 않습니다. 처음부터 차단된 상품은 즉시 숨깁니다.

1.4.0 변경
- 차단을 누르면 해당 판매자의 카드가 약 0.9초 동안 검은 재처럼 흩어집니다.
- 효과가 끝나면 남은 카드들이 빈자리로 부드럽게 이동합니다. 목록 페이지를 새로고침하지 않습니다.
- 상세 페이지에서는 본문에 효과를 적용한 뒤 기존처럼 이전 페이지 또는 스토어 홈으로 이동합니다.
- 처음부터 차단된 판매자와 다른 탭에서 차단한 판매자는 즉시 숨깁니다.
- 숨겨진 탭에서는 효과를 생략합니다.
- 화면에 보이는 최대 8개 영역에 효과를 적용하고 나머지 해당 판매자 카드는 함께 숨깁니다.
- 차단 저장에 실패하면 화면을 유지합니다. 효과 중 숨기기를 끄거나 차단을 해제하면 복원됩니다.

1.3.2 변경
- 확장 아이콘을 회색 방패와 빨간 차단 표시의 클래식 픽셀 스타일로 변경했습니다.
- Edge 툴바, 확장 관리 화면, 관리 페이지 제목줄과 파비콘에 함께 적용했습니다.
- Unity·BOOTH의 차단 버튼도 회색 사각 버튼과 입체 테두리로 통일했습니다.

1.3.1 변경
- 관리 페이지를 Windows XP 시절의 간결한 관리 화면 스타일로 변경했습니다.
- 화면 바깥 여백, 큰 소개 문구, 둥근 카드와 판매자 아바타를 제거했습니다.
- 작은 글씨, 파란 제목 표시줄, 회색 도구 모음과 촘촘한 목록을 사용합니다.
- 브라우저 테마 자동 적용과 라이트·다크 선택은 그대로 유지됩니다.

1.3.0 변경
- 사이트에는 판매자 이름 옆 차단 버튼만 표시합니다.
- 사이트 내 차단 해제·실행 취소 버튼과 우측 하단 패널을 제거했습니다.
- 목록에서는 해당 판매자의 상품을 즉시 숨깁니다.
- 상세의 판매자를 차단하면 저장 직후 이전 페이지로 돌아갑니다.
- 이전 페이지가 없는 새 탭에서는 스토어 홈으로 이동합니다.
- 차단 확인이나 복구 안내 창을 표시하지 않습니다.

1.2.1 변경
- 보라색 방패와 흰색 S 모노그램의 SlopBlock 전용 아이콘을 추가했습니다.
- Edge 툴바·확장 관리 화면·관리 페이지 로고·탭 파비콘에 적용했습니다.
- icons/slopcut.svg는 편집 가능한 벡터 원본입니다.
- PNG는 16 / 24 / 32 / 48 / 64 / 128 / 256 / 512px로 제공됩니다.

1.2.0 변경
- 확장 이름을 SlopBlock으로 변경했습니다.
- 관리 페이지의 테마: 브라우저 설정 따르기 / 라이트 / 다크.
- 기본값은 브라우저가 제공하는 기본 색상 모드(prefers-color-scheme)를 따릅니다.
- 브라우저 설정 따르기에서는 기본 모드가 바뀌면 열린 관리 화면에도 바로 반영됩니다.
- 직접 고른 테마는 이 Edge 프로필에 저장되며 관리 페이지를 다시 열 때 유지됩니다.
- 테마 설정은 차단 목록과 별도로 저장됩니다.

기존 버전에서 업데이트
1. 기존에 설치했던 폴더 그대로 사용합니다. 확장을 삭제하지 마세요.
2. edge://extensions 에서 이 확장의 새로 고침 버튼을 누릅니다.
3. BOOTH 사이트 접근 허용을 Edge가 요청하면 허용합니다.
4. Unity·BOOTH 탭과 열려 있는 관리 페이지를 새로고침합니다.
기존 Unity 차단 목록과 전체 활성화 설정은 자동 호환됩니다.

처음 설치
1. Edge에서 edge://extensions 를 엽니다.
2. 개발자 모드를 켜고 '압축 풀린 파일 로드'를 누릅니다.
3. 이 manifest.json이 들어 있는 폴더를 선택합니다.
4. 이미 열려 있던 대상 사이트 탭을 새로고침합니다.

사용
- Unity 검색·추천 카드와 상세 페이지에서 제작자 이름 오른쪽 '차단'을 누릅니다.
- BOOTH 검색·카테고리·홈 추천·상품 상세에서 상점 이름 오른쪽 '차단'을 누릅니다.
- BOOTH 개별 상점 테마에서는 상점 이름 오른쪽에서 차단하고 상품 카드를 숨깁니다.
- 관리 화면은 Edge의 딸깍컷(SlopCut) 확장 아이콘으로 엽니다.
- 관리 화면: 사이트 필터, 사이트별 활성화, 이름·ID 검색, 직접 추가, 해제, JSON 백업·복원.
- 사이트에서 새로 차단한 카드에는 검은 먼지 효과가 적용됩니다.
- 직접 추가: Unity 제작자 URL/숫자 ID, BOOTH 상점 URL/상점 서브도메인.
- 전체 해제는 선택한 사이트를 대상으로 합니다. 사이트 필터가 '전체'이면 모든 목록을 해제합니다.
- 백업은 항상 전체 사이트의 목록을 포함합니다. 기존 v1 Unity 백업도 가져올 수 있습니다.

저장과 권한
- Unity는 제작자 숫자 ID, BOOTH는 상점 서브도메인으로 식별합니다.
- 사이트+ID로 구분하므로 같은 ID나 이름의 다른 사이트 판매자와 충돌하지 않습니다.
- BOOTH의 상점 주소 자체가 바뀌면 새 주소를 다시 차단해야 합니다.
- 차단 목록은 이 Edge 프로필 로컬 저장소에만 보관하며 외부 서버로 전송하지 않습니다.
- storage 권한과 assetstore.unity.com, booth.pm 및 *.booth.pm의 콘텐츠 스크립트만 사용합니다.
- BOOTH 로그인·관리·결제·문의 화면에는 버튼이나 숨김 처리를 적용하지 않습니다.

참고
- 설치한 폴더를 삭제하거나 옮기지 마세요. ZIP은 이동·백업용입니다.
- 사이트의 검색 결과 수/페이지 수는 원래 값입니다. 숨김만큼 표시 상품이 적어집니다.
- 판매자 표시가 없는 최근 본 상품의 썸네일은 대상이 아닙니다.
- 사이트의 페이지 구조가 변경되면 해당 어댑터를 업데이트해야 할 수 있습니다.
- 확장을 삭제하면 로컬 차단 목록도 삭제될 수 있으니 먼저 백업을 내보내세요.
