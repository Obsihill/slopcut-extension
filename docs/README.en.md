# SlopCut (딸깍컷)

Hide products from sellers you choose on Unity Asset Store and BOOTH.
Click the small button beside a seller name; matching product cards dissolve into dark dust and the remaining cards move into place without reloading the listing.

The extension name is localized to 딸깍컷 in Korean and SlopCut otherwise. The settings interface, status messages, and injected buttons currently use Korean.

Supported features: seller blocking, cross-tab updates, site-specific pause controls, list filtering, manual seller entry, unblocking, local JSON backup/merge, and light/dark/system appearance.
The extension does not classify content as AI-generated and does not submit reports or blocks to marketplace accounts.
A block on the main seller of a product detail page returns to the previous page after the effect, or the marketplace home if there is no previous page.

For a development install, open `edge://extensions`, enable Developer mode, and load the repository's `extension/` folder. Refresh already-open marketplace tabs. No runtime dependencies or build step are required.
Back up your list before switching from an unpacked install to a store install.
