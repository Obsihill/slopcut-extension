# 딸깍컷 / SlopCut 개인정보처리방침

작성일: 2026년 10월 17일 · 적용 대상: Microsoft Edge용 딸깍컷 / SlopCut 1.5.0–1.6.0 및 Google Chrome용 1.6.0

## 1. 목적과 처리 위치

딸깍컷은 사용자가 Unity 에셋스토어, BOOTH, CGTrader, Fab, TurboSquid에서 선택한 판매자의 상품을 현재 브라우저 화면에서 숨깁니다.
확장 기능을 사용하기 위한 별도의 서비스 계정이나 개발자 서버가 없습니다.
판매자 차단 목록과 설정은 현재 브라우저 프로필의 확장 저장소에서 처리됩니다. Chrome과 Edge의 목록은 자동으로 공유되지 않습니다.

## 2. 페이지에서 읽는 정보

지원되는 페이지의 HTML에서 판매자 링크, 표시 이름, 제작자 ID 또는 BOOTH 상점 주소와 상품 카드 영역을 식별합니다.
이 정보는 차단 버튼 배치와 선택한 판매자의 상품 숨김에 사용합니다.
페이지 정보 전체를 개발자 서버에 보내거나 방문 내역을 기록하는 기능은 없습니다.
개별 상점 테마의 상품 카드에는 해당 페이지의 상점 서브도메인을 판매자 식별자로 사용하기도 합니다.

## 3. 기기에 저장하는 정보

- 차단한 판매자의 사이트 구분, 제작자 ID 또는 상점 서브도메인, 표시 이름, 추가 시각
- 전체 숨김 활성화 여부와 사이트별 활성화 여부
- 테마 선호(브라우저 설정 따르기 / 라이트 / 다크)

`chrome.storage.local`의 state와 uiTheme를 사용합니다. 첫 화면 테마를 적용하기 위한 확장 페이지 localStorage 캐시도 사용합니다.
기존 설치와의 호환을 위해 캐시 키 slopblock.theme는 유지합니다. 이는 과거 이름의 내부 저장 키입니다.
로그인 자격 증명, 쿠키, 결제 정보, 구매 내역, 전체 브라우징 내역을 읽거나 저장하는 기능과 권한은 요청하지 않습니다.

## 4. 외부 전송과 제3자

차단 목록과 설정을 개발자 또는 제3자에게 전송하지 않습니다. 사용 분석, 원격 오류 수집, 광고 추적 SDK도 포함하지 않습니다.
실행 코드는 설치 패키지에 포함되며 원격 코드를 불러오지 않습니다.
1.6.0부터 TurboSquid 목록에서 판매자가 표시되지 않는 경우, 화면 가까이에 있는 카드의 같은 사이트 공개 빠른 보기 HTML을 요청하여 판매자 이름과 프로필 주소를 읽습니다. 요청은 동시에 최대 2개이며 같은 페이지에서 읽은 결과를 재사용합니다. 차단 목록을 요청에 포함하지 않으며, 받은 HTML의 스크립트는 실행하지 않습니다. 이 요청에는 사이트의 일반적인 동일 출처 쿠키 처리가 적용되지만 확장은 쿠키 값을 직접 읽거나 저장하지 않습니다. 사이트가 요청을 거부하면 해당 카드에는 판매자 버튼이 표시되지 않을 수 있습니다.
원래 웹사이트의 통신과 데이터 처리는 각 웹사이트의 개인정보처리방침을 따릅니다. 판매자 링크를 직접 열면 해당 사이트로 이동합니다.
확장을 배포하는 Chrome 웹스토어, Microsoft Edge Add-ons 또는 GitHub/GitHub Pages가 자체적으로 처리하는 접속·배포 관련 정보는 각 플랫폼의 정책을 따릅니다.

Chrome 웹스토어 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 따릅니다. 페이지의 판매자 정보와 저장된 선택은 판매자 차단·관리 기능에만 사용하며, 개인화 광고, 데이터 판매, 신용평가, 기능과 무관한 목적에 사용하거나 전송하지 않습니다. 개발자가 이 로컬 목록을 열람하는 기능은 없습니다.

## 5. 백업 파일

사용자가 내보내기를 누르면 차단 목록의 사이트, ID, 표시 이름, 추가 시각을 포함하는 JSON 파일을 브라우저 다운로드 방식으로 생성합니다.
테마와 숨김 활성화 설정은 차단 목록 백업에 포함되지 않습니다.
가져오기는 사용자가 선택한 JSON 파일을 기기에서 읽어 기존 차단 목록에 합칩니다. 개발자에게 업로드하지 않습니다.
파일을 다른 사람에게 공유하면 그 사람이 차단 목록을 볼 수 있으므로, 공유와 보관은 사용자가 결정합니다.

## 6. 보관과 삭제

사용자가 관리 페이지에서 차단을 해제하거나 목록 전체를 비우면 해당 판매자 기록이 확장 저장소에서 제거됩니다.
확장을 제거하면 브라우저가 확장 저장소를 삭제합니다. 사용자가 내보낸 JSON 파일은 확장 제거와 별개이며 직접 삭제해야 합니다.
서버 사본이 없으므로 개발자가 차단 목록을 복구하거나 대신 열람할 수 없습니다.

## 7. 애니메이션

먼지 효과는 기기에서 생성한 노이즈 마스크와 입자로 구성됩니다. 스크린샷 촬영, 상품 이미지 픽셀 읽기, 이미지 외부 전송을 하지 않습니다.
사용자가 직접 차단하거나 미리보기를 누르면 OS 동작 줄이기 설정과 관계없이 효과를 재생합니다. 비활성 탭에서는 효과를 생략합니다.

## 8. 문의와 변경

문의는 이 확장을 배포하는 공식 GitHub 저장소 slopcut-extension의 Issues를 이용해주세요. 개인정보나 차단 목록 전체를 공개 이슈에 올릴 필요는 없습니다.
처리 항목이나 외부 전송 방식이 달라지면 코드와 함께 이 문서의 작성일 및 설명을 갱신합니다.
