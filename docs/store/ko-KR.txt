확장 이름
딸깍컷

짧은 설명 — manifest의 ko 메시지와 동일
Unity 에셋스토어와 BOOTH에서 판매자 이름 옆에 차단 버튼을 표시하고 차단한 판매자의 상품을 숨깁니다.

상세 설명
보고 싶지 않은 판매자의 상품을 딸깍 한 번으로 정리하세요.

딸깍컷은 Unity 에셋스토어와 BOOTH의 판매자 이름 옆에 작은 차단 버튼을 추가합니다. 누르면 해당 판매자의 상품을 검색·추천 목록에서 숨깁니다. 사이트 계정을 변경하거나 판매자를 신고하지 않고, 내 브라우저의 표시만 바꿉니다.

주요 기능
• 목록과 상품 상세의 판매자 이름 옆에서 차단
• 차단한 카드가 검은 재처럼 흩어지는 효과와 부드러운 목록 재배치
• 사이트별 숨김 켜기/끄기
• 차단 목록 검색, 사이트 필터, URL·ID로 직접 추가, 차단 해제
• JSON 파일로 백업 내보내기와 기존 목록에 합쳐서 가져오기
• Windows XP 스타일 관리 화면과 라이트·다크·브라우저 테마 연동

사용 방법
1. Unity 에셋스토어 또는 BOOTH를 엽니다.
2. 판매자 이름 오른쪽 차단을 누릅니다.
3. 확장 아이콘을 누르면 차단 목록을 관리할 수 있습니다.

데이터 처리
차단 목록과 설정은 현재 브라우저 프로필에 저장됩니다. 확장 자체의 서버, 사용 분석, 광고 추적, 계정 가입이 없습니다. 사용자가 직접 내보낸 백업 파일은 사용자가 관리합니다.

알아두세요
이 확장은 AI 생성물 여부를 판정하지 않으며, 사용자가 선택한 판매자만 숨깁니다. 사이트가 표시하는 검색 결과 수와 페이지 수는 변경하지 않습니다. 사이트 구조나 개별 BOOTH 상점 테마에 따라 일부 화면에서는 동작하지 않을 수 있습니다. 상세 화면에서 주 판매자를 차단하면 효과 뒤 이전 페이지 또는 스토어 홈으로 이동합니다. 이미 차단된 상품은 즉시 숨겨집니다. 직접 요청한 애니메이션은 OS의 동작 줄이기 설정과 관계없이 재생됩니다.

Unity, BOOTH 또는 Microsoft의 공식 확장이 아닙니다.
