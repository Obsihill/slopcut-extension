# BOOTH 수정 확인 — 1.6.1

2026-10-20

BOOTH 홈 추천 상품은 `.item-card__wrap`과 전용 판매자 클래스 대신 `.item-card-wrapper` 내부의 일반 상점 링크를 사용합니다. 기존 코드에서는 이 영역의 버튼과 차단 대상 카드가 식별되지 않았습니다. 검색 목록과 주 판매자의 상세 영역은 기존 구조도 사용하므로 두 구조를 함께 지원합니다.

새 구조의 판매자 링크만 인라인으로 배치해 버튼이 이름 오른쪽에 붙도록 했습니다. 카테고리·제목·가격이 들어 있는 상위 영역을 flex로 바꾸지 않습니다. 기존 상점 ID와 저장 형식, 권한은 유지합니다.

- 기존 코드에서 새 회귀 테스트가 실패함을 확인: 버튼 4개 대신 기존 카드의 1개만 표시.
- 수정 후 기능 테스트 27개와 격리된 Microsoft Edge 브라우저 테스트 12개, 총 39개 통과.
- 격리된 Google Chrome에서도 같은 브라우저 테스트 12개 통과.
- 새 추천 카드와 기존 카드가 섞인 동일 판매자 차단, 전체 셀 숨김, 새로 추가된 카드, 차단 해제, 잘못된 링크 제외 검사.
- 상세 페이지의 추천 카드 차단은 이전 페이지로 이동하지 않는지 검사.
- 브라우저에서 데스크톱·좁은 화면의 버튼 위치, 먼지 효과, 다른 카드의 빈자리 이동을 검사.
- 실제 사용 중인 Edge 확장을 1.6.1로 다시 로드한 뒤 BOOTH 홈의 추천 판매자 링크와 버튼이 같은 높이에 나란히 배치됨을 확인. 검색 페이지 버튼 60개와 상세 페이지 버튼 표시도 확인.
- 실제 사용자 프로필에서는 테스트 차단 목록을 추가하지 않았습니다. 저장·효과·복구 검사는 격리된 브라우저의 모의 저장소로 수행했습니다.
- 릴리스 파일·권한·로캘·이미지 검사 및 ZIP 내부 파일과 소스 일치 검사 통과.

Edge 1.6.1은 Partner Center에서 In review로 접수 확인했습니다. 기존 1.6.0은 Live입니다. Chrome ZIP은 준비 상태이며 Chrome 웹스토어 심사에 제출된 것은 아닙니다.
