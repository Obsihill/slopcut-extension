# 딸깍컷 / SlopCut

보기 싫은 판매자, 딸깍 한 번으로 컷.

판매자 이름 옆 **차단**을 누르면 그 판매자의 상품이 사라집니다.
현재 지원: **Unity Asset Store · BOOTH**  
지원 사이트는 확장 중…

### 차단 목록 관리

확장 아이콘을 누르면 열립니다. 차단 해제, 목록 검색, 백업, 테마 변경은 여기서 합니다.

<img src="docs/store/screenshots/03-management-light.png" width="560" alt="차단 목록 관리 화면">

### 설치

Edge 스토어 등록 준비 중입니다. 지금은 직접 설치할 수 있습니다.

1. [소스 ZIP](https://github.com/Obsihill/slopcut-extension/archive/refs/heads/main.zip)을 받아 압축을 풉니다.
2. `edge://extensions`에서 **개발자 모드**를 켭니다.
3. **압축 풀린 파일 로드**를 누르고 `extension` 폴더를 선택합니다.
4. 열려 있던 스토어 탭을 새로고침합니다.

설치한 폴더는 그대로 두세요. 다른 설치로 옮길 때는 관리 화면에서 차단 목록을 백업하면 됩니다.

차단 목록은 내 브라우저에 저장됩니다. AI 생성물을 자동으로 판별하는 기능은 없습니다.
사이트가 바뀌면 일부 화면에서 동작하지 않을 수 있습니다.
